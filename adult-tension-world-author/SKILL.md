# Adult Tension 世界包写作

产出是一份能直接放进 Adult Tension 的世界包 JSON 文件，`world_check.py check` 零问题通过。全部内容是成年人之间的故事。

## 文件

本 Skill 目录里（下文路径都相对这个目录）：

- `references/guide.md`：写作指南。**动笔前完整读一遍**，尤其第 0 节（红线、两人开局、最常返工的写法、字数上限）。第 1–16 节按 JSON 顺序写，每节标题后面标了对应字段。
- `references/fields.md`：全部字段的类型、上限和说明，查字段时看。
- `references/example_world.json`：一个已上线的完整世界包，照它的结构写。注意它的人物组合是两个 NPC 的旧写法；新世界按指南 0.3 节，每个组合只放 1 个 NPC。
- `scripts/world_check.py`：检查器，只需要 Python 3.10+ 标准库。依次试 `python3`、`python`、`py -3`；版本太低就告诉用户，不要自己安装或改系统环境。

## 步骤

1. **定设定**。和用户确认：题材与时代、地方、标题人物、想要的气氛（日常为主还是压力为主）。用户没说的按时代常识补齐，不逐项追问；一次最多问一轮。用户给了草稿或填好的模板，就以它为准，只补缺的。
2. **生成骨架**：
   `python scripts/world_check.py new <世界id> --title 标题 --era 时代 --region 地方 --out <输出目录>`
   输出目录用用户指定的位置；没指定就用当前工作目录。`id` 用小写字母、数字、下划线。
3. **逐节写**。按指南第 1–16 节的顺序直接编辑这份 JSON。数量按指南建议写（下限只是地板）。写到一半就可以跑检查，结构问题先改掉，后面的开局检查才跑得起来。
4. **检查到通过**：
   `python scripts/world_check.py check <文件>`
   问题一次列全，每条有 JSON 路径、原因和改法。逐条改，再跑，直到显示“通过”。
   - 只靠补内容和改写达标：不要删内容躲检查，不要改检查器。
   - 开局多样性不过：按提示补组合、活动、压力、钩子或身份，让 4 种权力结构都能开、approach 钩子过六成。
   - 男/女玩家开不出局：给那种性别补能配上的组合和 NPC（any 或相反性别）。
5. **自查红线**。检查器查不出内容红线（指南第 0 节“一、内容红线”和文末自查清单）：全员成年、无幼态描写；不拿把柄、钱、救命换亲密；亲密只在清醒、自愿时；无胁迫、性威胁；出路和代价不涉性。逐条过一遍，有问题改完再跑一次检查。
6. **交付**。告诉用户文件路径，并说明：
   - `status` 是 `draft`，放进 Adult Tension 项目的 `content-src/worlds/` 后，由那边编译和做跨世界查重（和已有世界高度相似的段落只有在那边才能查出来）。
   - 简要列出：世界一句话简介、NPC 名单、组合的权力结构分布、压力来源分布。

## 写作要点（细则在指南里）

- 两人开局：每个人物组合 1 个 NPC；NPC 性别一般写 `any`，开局自动和玩家相反；`any` 的人全文不写“他/她”，用 `{npc.ta}`、`{槽位.ta}` 或身份称呼。
- 不写死人名，用 `{模板id.name}`、`{npc.name}`；称呼玩家用 `{player.title}`、`{player.call}`。
- 压力里至少 2 个来自人、制度、钱或流言，不要全是天灾事故；日常活动写平常日子，配平静的钩子。
- 同一个世界里整句不重复，也不要从别的世界照抄。
