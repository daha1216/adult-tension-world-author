# 世界包写作指南

写 Adult Tension 世界包时逐节对照本文。第 0 节是红线和最常返工的地方，第 1–16 节按世界包 JSON 的顺序写，每节标题后面是对应的 JSON 字段；字段的类型和上限见 `fields.md`，完整的样子见 `example_world.json`。
写完用 `scripts/world_check.py check` 检查，问题一次列全，逐条改到通过。

写之前先看第 0 节的硬性红线，再看第 0.3 节的“两人开局”：新世界每一局开场都只有两个人，一男一女。

## 0. 硬性红线（违反就会整段重写）

| 规则 | 说明 |
|---|---|
| **全员成年** | 学生、师生、校园、学徒、徒弟、门生、弟子、少年、少女等词都可以用，但同一句里要注明是成年人（如“已成年的研究生”“成年弟子”）。严禁未成年心智与纯幼态表述。 |
| **不准交换** | 不写拿把柄、钱、救命、帮忙去换亲密，也不写以亲密作为条件。 |
| **必须清醒** | 不写醉酒、下药、中毒、发烧、诅咒发情、神志迷离时的亲密。生病、受伤可以写，但亲密只能放在痊愈、完全清醒之后。 |
| **不准胁迫** | 不写强迫、性威胁、羞辱性占有。反派可以威胁人身安全，但不能带性的意味。 |
| **出路不涉性** | 各种“出路”和“代价”里不能出现“用身体换”这类选项。 |
| **不用 他/她** | 性别为 any 的人，性别开局时才定（见 0.3），正文一律写 `{槽位.name}`、身份称呼（大小姐、医生），要用代词时写 `{npc.ta}` / `{槽位.ta}`，别写死“他”“她”。 |
| **称呼对得上性别** | 先生、小姐、少爷、哥、姐这类带性别的称呼，只给性别已定的人；正文里不写“{player.name}先生”，用 `{player.title}` 或 `{player.call}`。 |
| **不重复句子** | 同一个世界里整句不能出现两次（包括出路、代价、台词）；和别的世界高度相似的段落也会被报出来，别从旧世界复制。 |
| **篇幅上限** | 一个 NPC 模板全部文字合计 ≤ 1800 字，一个压力事件 ≤ 450 字（见 0.5 B）。 |
| **知名作品角色名** | ✅ 可以用（贾宝玉、孙悟空、千寻、柯南等都行），真实人物姓名也可以用。 |

### 完整禁用清单

**一、内容红线（编译器查不出来，检查器查不出来，写的时候自己把关，交稿前逐条自查）**
1. 未成年人，以及稚气、奶声奶气等纯幼态描写。
2. 用把柄、金钱、救命、帮忙、封口去换取亲密，或把亲密当作交换条件。
3. 醉酒、下药、中毒、高烧、诅咒、催眠、昏迷等神志不清状态下的亲密。
4. 强迫、性威胁、性暴力、羞辱性占有。
5. 出路、代价、选项里出现“用身体换”这类内容。

**二、编译器会直接报错的**
| 检查 | 规则 |
|---|---|
| 年龄 | 所有人物（NPC、背景人物、玩家身份）年龄下限 ≥ 18；NPC 模板和背景人物都要写成年说明。 |
| 学生类词语 | 学生、师生、校园、学徒、徒弟、门生、弟子、少年、少女、幼、童：同一段或该人物的成年说明里，要出现成年、成人、研究生、夜校、驻留、年满、已婚、正式工、正式雇员、持证其中之一。 |
| 他/她 | 性别为 any 的人物，文本里不能写死“他”“她”，用 `{npc.ta}`。 |
| 称呼 | 带性别的称呼模板、昵称模板要标 male 或 female；性别 any 的玩家身份要同时有给男玩家和女玩家的称呼（或一个不带性别的称呼，如“{family}老师”）；正文里不许“{player.name}先生”这种写法。 |
| 重复句 | 同一个世界里，整句不能重复；高度相似（≥85%，16 字以上）的段落也会报出来，跨世界也查。 |
| 占位内容 | 不能写 —、-、待补、待定、TODO、TBD、...、……、无、暂无、占位、xxx、N/A，或者和字段名一样的文字。 |
| 本世界禁用词 | 自己在“禁用词”里列出的、和时代不符的词，全文都不能出现。 |
| 字数 | 每个字段都有上限，见 0.5 B；一个 NPC 模板合计 ≤ 1800 字，一个压力 ≤ 450 字。 |
| 地点 | 通路必须双向、全部连通；至少 1 个 public，加 1 个 semi 或 private；任意两个地点的私密度、可见性、可做的事不能完全一样。 |
| 引用 | 引用的地点、钩子、人物、压力、引擎、背景人物 ID 都必须真实存在；同一世界里 ID 不能重名；`player` 是保留字。 |
| 覆盖 | 人物组合要覆盖 4 种权力结构；玩家身份要覆盖 low、equal、high；渠道要有 exact 和 distorted；钩子里 approach 要超过一半；每个组合至少有一个玩家身份配得上。 |
| 压力 | 立即、近期、远期三层都写；近期期限的分钟数 > 立即层分钟数；出路 ≥ 2 条且各有代价；标了“把柄”的压力要写清谁握着谁的把柄、凭什么。 |
| 标签 | 只能用第 1 节列出的内容标签。 |
| 数量下限 | 规则 4、习俗 4、名字每类 12、昵称格式 2、玩家身份 4、地点 3、NPC 模板 6、背景人物 6（≥3 种作用）、渠道 2、张力引擎 4、人物组合 4、日常活动 6、压力 6、钩子 4、转折 6（≥4 类）。下限是地板，下面各节建议的数量更稳。 |

**三、开局检查（`world_check.py check` 会跑，不过就要补内容）**
| 检查 | 要求 |
|---|---|
| 两种性别都能开 | 玩家身份允许的每种性别（男、女），日常和压力两种模式都要开得出局。 |
| 多样性 | 每种模式连续随机开 20 局：至少 12 种不同的开局；4 种权力结构各占 ≥ 15%；至少出现 3 个不同的玩家身份；approach 钩子占 ≥ 60%。 |

**好冲突的写法**：用两难选择代替胁迫。比如“举报还是保护”“救这个人还是守规矩”“签不签离婚协议”，让每条路都有代价，但没有一条路是拿身体换的。

## 0.3 两人开局：一男一女（新世界都按这个写）

- **每个人物组合只放 1 个 NPC**。开局在场的主要人物就是玩家和这一个 NPC，两个人。背景人物照常写，他们只是氛围和路人，不算开局的人物。
- **一男一女由引擎自动配**：玩家没说性别就按男性；NPC 模板性别写 `any`，开局时自动取和玩家相反的性别。所以默认是男玩家配女 NPC，玩家说“我玩女的”时 NPC 自动变成男性。
- 因为 NPC 可能是男也可能是女，any 的 NPC 全文不写“他/她”，外貌、称呼都要男女皆可（不写胡茬、裙子这类只属于一种性别的细节）。
- **确实要固定性别的 NPC**（标题人物、女骑士、修女这类）：写 female 或 male 并写一句理由。固定为女性的 NPC 只会配男玩家，固定为男性的只会配女玩家，这个配对自动保证一男一女。
- **玩家身份**一般写 any（称呼男女各给一个）。身份写死性别的，它所在组合的 NPC 要么是 any，要么是相反性别，不然这个组合永远开不出来。
- 只要有一个玩家身份允许女玩家，世界里就得有能配女玩家的 NPC（any 或 male），否则“两种性别都能开”的检查不过。
- **关系只写 1 条**：玩家—NPC。
- **钩子跟着 NPC 走**：一局的开场钩子只能来自这一局的那个 NPC，所以每个 NPC 都要有自己的钩子（建议每人 3 个：approach 2 个 + request/observe 1 个），钩子地点要覆盖这个 NPC 会出现的活动和压力地点（不写地点表示哪儿都行）。
- 化学反应、资源差、底线差、见面理由都只写玩家和这一个 NPC 之间的事。

## 0.5 最近几份稿子最常返工的地方（按这里写，单个世界能从半小时降到几分钟）

### A. 内容：最耗时的返工
| 原稿常见写法 | 改成 |

### C. 结构要对得上
- **组合里出现的人都要有定义**：组合的玩家身份 id 必须在“玩家身份”里有；NPC id 必须在“NPC 模板”里有。想让某人既能当 NPC 又能被玩家扮演，两边都写一份（文字别写成一样的）。
- **每个 NPC 模板至少进一个组合**，否则它的钩子永远用不上，会报错。
- **组合的玩家位置要和身份对得上**：组合里限定的身份，其社会位置必须在这个组合的“玩家位置”里。
- **背景人物至少 3 种作用**（witness、obstacle、messenger、rumor_source、helper 混着用）。
- **钩子里 approach 要超过一半**，而且每个 NPC 都要有 approach 钩子。
- **名字池每类至少 12 个**（姓、女名、男名、中性名），同一个名字不能放进两个名池。
- **同一句话不要在玩家身份和 NPC 模板里各写一遍**（资源最常撞）。
- **直接显示的字段不用占位符**：NPC 的成年说明、公开身份、固定性别理由，背景人物的职务和名字，活动标题，这些原样显示，不能写 `{xxx}`。
- **占位符能用在哪**：NPC 模板和背景人物用 `{npc.xxx}`、`{player.xxx}`；钩子用 `{npc.xxx}`（就是钩子的 NPC）、`{player.xxx}`；组合用 `{模板id.xxx}` 和 `{player.xxx}`；转折用 `{模板id.xxx}` 和 `{player.xxx}`；压力只能用 `{player.xxx}`（带把柄的再加把柄双方）；日常活动只能用 `{player.xxx}`；世界简介、规则、地点、玩家身份、张力引擎、渠道不用占位符（玩家身份的称呼格式除外）。可用属性：name、ta、family、given、call、role、title；`{family}`、`{given}`、`{given_last}` 只用在称呼和昵称格式里。

### D. 人名
- 台词和钩子里**不写死人名**（如“静香”“橘川剑士”），用 `{模板id.name}`、`{npc.name}` 或职称（巫女长、剑士）。
- 写进剧情的家族名（如“橘川家”）**不要放进姓氏池**。
- 需要固定性别的角色（标题人物、自称“老子”的人等），在“性别理由”里写一句，并按 0.3 检查配对。

